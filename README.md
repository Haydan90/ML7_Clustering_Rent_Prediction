# ML7 — Кластеризация и предсказание стоимости аренды

В этом проекте я исследовал, как можно использовать кластеризацию для улучшения предсказания стоимости аренды квартир. Я сравнил несколько алгоритмов кластеризации и проверил, как добавление номера кластера в признаки влияет на качество Lasso-регрессии.

## Датасет

Для проекта использовались данные об объявлениях аренды недвижимости из соревнования [Two Sigma Connect: Rental Listing Inquiries на Kaggle](https://www.kaggle.com/competitions/two-sigma-connect-rental-listing-inquiries/data).

Данные содержат информацию об объявлениях, включая количество спален и ванных комнат, характеристики квартир, уровень интереса к объявлению и географические координаты.

Файлы с данными в репозиторий не добавлены. Для запуска проекта необходимо подготовить файлы `train.csv` и `test.csv` и поместить их в папку `data`.

## Что было сделано

### 1. Предварительная обработка данных

- Обработал список характеристик квартир из столбца `features`.
- Выделил наиболее часто встречающиеся характеристики и преобразовал их в бинарные признаки.
- Подготовил признаки для обучения модели и целевую переменную `price`.

### 2. Реализация K-Means

Реализовал собственный класс `MyKMeans` и сравнил его результаты с реализацией из `scikit-learn`.

Для кластеризации по географическим координатам использовал 30 кластеров. Качество оценивал с помощью inertia и silhouette score.

### 3. Сравнение алгоритмов кластеризации

Проверил несколько подходов:

- **K-Means** — разбивает объекты на заданное количество кластеров.
- **DBSCAN** — выделяет группы на основе плотности объектов и позволяет определять шумовые точки. Также реализовал собственный класс `MyDBSCAN`.
- **Agglomerative Clustering** — иерархическая кластеризация, в которой группы постепенно объединяются.
- **Gaussian Mixture** — вероятностная модель, предполагающая, что данные образованы смесью нескольких распределений.

В первую очередь кластеризация выполнялась по координатам `latitude` и `longitude`. Дополнительно я проверил вариант кластеризации по другим признакам.

### 4. Добавление кластеров в признаки

После кластеризации добавил номер кластера в исходные признаки квартир. Затем сравнил качество Lasso-регрессии с исходным набором признаков и с добавленным кластерным признаком.

Для оценки использовал MAE, RMSE и \(R^2\).

### 5. Теоретические задания

Также рассмотрел несколько вопросов:
- способы инициализации центроидов для K-Means;
- использование кластеризации и KD-tree для ускорения поиска ближайших соседей в KNN.

## Результаты

Сравнение качества Lasso-регрессии на тестовой выборке:

| Модель | MAE | RMSE | R² |
|---|---:|---:|---:|
| Lasso без кластеризации | 679.44 | 972.07 | 0.6015 |
| Lasso + K-Means | 673.53 | 966.23 | 0.6063 |
| Lasso + DBSCAN | **668.28** | **962.04** | **0.6097** |
| Lasso + Agglomerative Clustering | 701.00 | 1061.84 | 0.5530 |
| Lasso + Gaussian Mixture | 674.41 | 967.26 | 0.6055 |

По результатам экспериментов, лучший результат среди рассмотренных вариантов показала модель Lasso с кластерным признаком, полученным с помощью DBSCAN. По сравнению с базовой моделью MAE уменьшилась примерно на 11.17, а \(R^2\) вырос с 0.6015 до 0.6097.

При этом улучшение оказалось небольшим. K-Means также дал положительный результат, а Agglomerative Clustering в данном эксперименте ухудшил качество предсказания.
